## 🚀 Projects

### 🔒 Spectre Browser
<div align="left">

[![Version](https://img.shields.io/badge/version-v2.0.0-blue?style=for-the-badge)](https://github.com/WavierPigeon261/spectre-browser/releases)
[![Platform](https://img.shields.io/badge/platform-Windows-green?style=for-the-badge)](https://github.com/WavierPigeon261/spectre-browser)
[![Status](https://img.shields.io/badge/status-Production-brightgreen?style=for-the-badge)](https://github.com/WavierPigeon261/spectre-browser)

A lightweight desktop browser engineered for **total digital privacy**.  Built on the privacy-hardened foundations of LibreWolf with a custom control plane: hardened default profiles, custom search omnibox routing, and a native C#/WPF updater engine. 

**Key Features:**
- Zero telemetry stack — no phone-home signals
- Standalone GUI updater (C#/WPF)
- Custom omnibox routing for private search providers
- Tabliss-inspired dark new-tab page 

[View Repository](https://github.com/WavierPigeon261/spectre-browser) | [Website](https://wavierpigeon261.github.io/spectre-browser/)
